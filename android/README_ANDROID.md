# Приложения для Android: Администратор, Тренер и Клиент

Платформа предоставляет **3 отдельных Android-приложения** с разными иконками, правами доступа и точками входа:

1. **Администратор** (`ru.etalonpravilo.admin`) — `/?app=admin`
   - Расписание, записи, клиенты, услуги, абонементы и рассылки.
   - Кабинеты тренера и клиента скрыты на уровне навигации и интерфейса.
2. **Тренер** (`ru.etalonpravilo.trainer`) — `/?app=trainer`
   - Кабинет тренера, смены, сессии с датчиками по Bluetooth, оценка осанки, база упражнений.
3. **Клиент** (`ru.etalonpravilo.client`) — `/?app=client`
   - Онлайн-запись, абонементы, динамика замеров и осанки, методические блоки, чат со студией.
   - База упражнений полностью скрыта как на сервере, так и в интерфейсе.

## Вариант 1. Мгновенная установка на Android через Chrome (WebAPK)

1. Откройте нужный адрес на смартфоне или планшете Android в браузере Chrome (по HTTPS):
   - Администратор: `https://ВАШ_ДОМЕН/?app=admin`
   - Тренер: `https://ВАШ_ДОМЕН/?app=trainer`
   - Клиент: `https://ВАШ_ДОМЕН/?app=client`
2. Нажмите кнопку **«Установить»** на экране входа (или откройте меню Chrome `⋮` → **«Установить приложение»**).
3. Каждое из трёх приложений устанавливается на Android как отдельная программа со своей иконкой.

## Вариант 2. Подготовка `.apk` / `.aab` пакетов для Android Studio / RuStore / Google Play

1. Выполните сборку фронтенда и генерацию конфигураций для вашего домена:
   ```bash
   npm run build
   npm run android:prepare -- --url=https://studio.yourdomain.ru
   ```
2. В папке `release-android/` будут созданы три каталога (`admin/`, `trainer/`, `client/`) с готовыми `capacitor.config.json`, `twa-manifest.json`, иконками и скриптом `build-apk.sh`.
3. Для сборки подписанного `.apk`/`.aab` в соответствующей папке выполните `./build-apk.sh` (требуются JDK 17+ и Android SDK) или откройте проект через Capacitor / Android Studio.
